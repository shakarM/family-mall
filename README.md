# family-mall

Interactive 3D mall map (Lumen Square) built with React, Three.js, Tailwind and Vite.

- `/` — combined version
- `/simple` — simple version
- `/pro` — pro version

## Run locally

```bash
npm install
npm run dev          # dev server
npm run build:site   # builds all three versions into site/
```

Hosted on Vercel: every push to `main` redeploys automatically.
